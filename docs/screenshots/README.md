# 界面截图

README 首屏预留了「界面预览」表格，把三张截图放进这个目录后，删掉 `README.md` 中那段注释即可生效。

| 文件名 | 拍什么 | 建议 |
|---|---|---|
| `01-draft.png` | 输入「明天下午写两小时报告，周五前交」后弹出的草案确认卡片 | 让卡片里同时出现一条任务和一条事件，能看出勾选与置信度 |
| `02-week.png` | 周视图，同一天有 2–3 个自动排好的任务块 | 选一个有部分占用的日子，能看出引擎在找空档 |
| `03-mobile.png` | 390×844 宽度下的日视图 | 用浏览器设备模拟截图即可 |

要求：

- 只截应用界面，不要带浏览器标签栏和个人信息
- DeepSeek Key 输入框不要出现在画面里
- 单张控制在 300 KB 以内（PNG 或 WebP）
