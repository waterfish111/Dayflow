## 怎么重新截

截图里的数据是造的，不是真实使用记录（仓库里不应出现个人信息）：

1. `pnpm build && pnpm start`（或 `pnpm dev`），用浏览器打开
2. 在控制台写入一份演示状态：`localStorage.setItem("dayflow.state.v1", JSON.stringify({...}))`
3. 桌面端用 DevTools 的设备模拟切成 390×844 出第三张图
4. 草案弹窗需要先填一个 Key 才能触发；若不想消耗额度，可在 DevTools 里用 Network 面板的 request blocking 或本地 mock 返回一份 JSON

要求：

- 只截应用界面，不要带浏览器标签栏、书签栏和个人信息
- DeepSeek Key 输入框不要出现在画面里
- 单张控制在 300 KB 以内（PNG 或 WebP）
